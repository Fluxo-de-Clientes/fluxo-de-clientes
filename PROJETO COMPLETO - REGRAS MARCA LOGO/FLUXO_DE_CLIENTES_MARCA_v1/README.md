**Escolha rápida:** original no fundo claro; reverso ou branco no fundo escuro. Preto técnico para uma tinta. SVG em sites e vetores; PNG em redes, e-mail e ferramentas que não aceitam SVG.

As matrizes do nome e símbolo são vetores desenhados especificamente para esta identidade e não dependem de fontes. Todos os PNG das matrizes têm transparência. Avatares, ícones e capas têm fundo sólido intencional. Não use uma prancha de demonstração como arquivo da logo.

**Favicon preservado.** A imagem enviada corresponde ao favicon do repositório e foi mantida byte a byte. Os novos símbolos não substituem o ícone da aba do navegador.

**Destino canônico:** copiar o conteúdo desta pasta para `docs/design/referencia-visual-canonica/marca/`. A documentação descreve os ajustes de precedência nos documentos atuais. Os arquivos ainda não foram publicados no GitHub nem aplicados ao site.
